<!-- ================= HEADER ================= -->
<h1 align="center">✋ ISL Gesture Recognition using Streamlit</h1>

<p align="center" style="max-width:760px; margin:18px auto; line-height:1.7; font-size:15px;">
  This project is a <b>real-time Indian Sign Language (ISL) hand gesture recognition system</b>
  developed as a <b>5th Semester Minor Project</b>.
  It uses computer vision and machine learning techniques to detect and classify
  ISL hand gestures directly through a web browser.
</p>

<hr/>

<!-- ================= PROJECT MOTIVATION ================= -->
<h2>🧠 Project Motivation</h2>
<p style="line-height:1.7;">
  Indian Sign Language (ISL) is an essential communication medium for the deaf and
  hard-of-hearing community.  
  This project explores how <b>hand landmark detection</b> and <b>machine learning</b>
  can be combined to recognize ISL gestures in real time and serve as a foundation
  for accessible communication systems.
</p>

<hr/>

<!-- ================= TECH STACK ================= -->
<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Streamlit</b> – Web interface and deployment (Streamlit Cloud)</li>
  <li><b>OpenCV</b> – Image capture and preprocessing</li>
  <li><b>MediaPipe</b> – Hand landmark detection</li>
  <li><b>Scikit-learn</b> – Machine learning framework</li>
  <li><b>RandomForestClassifier</b> – Gesture classification model</li>
  <li><b>Python</b> – Core programming language</li>
</ul>

<hr/>

<!-- ================= FEATURES ================= -->
<h2>📌 Features</h2>
<ul>
  <li>📷 Real-time gesture capture using a webcam</li>
  <li>🖐️ Accurate hand landmark extraction using MediaPipe</li>
  <li>🗂️ Dataset generation from live gesture images</li>
  <li>🧠 Machine learning-based gesture classification</li>
  <li>🌐 Browser-based inference using Streamlit</li>
  <li>☁️ Deployable on Streamlit Cloud for free</li>
</ul>

<hr/>

<!-- ================= DATASET ================= -->
<h2>📊 Dataset Details</h2>
<ul>
  <li>ISL alphabet hand gestures</li>
  <li><b>~1000 images collected per gesture</b></li>
  <li>Images captured using webcam under controlled conditions</li>
  <li>Hand landmarks extracted and used as feature vectors</li>
</ul>

<p>
  The dataset was manually collected and processed to ensure consistency
  and reliable training performance.
</p>

<hr/>

<!-- ================= ML PIPELINE ================= -->
<h2>🧪 Machine Learning Pipeline</h2>
<ol>
  <li>Capture gesture images using OpenCV</li>
  <li>Extract hand landmarks using MediaPipe</li>
  <li>Convert landmarks into numerical feature vectors</li>
  <li>Train a <b>Random Forest classifier</b> on the dataset</li>
  <li>Perform real-time inference through Streamlit</li>
</ol>
